# 🧠 Segundo Cérebro Especialista com NotebookLM

Este repositório documenta a criação de um especialista digital personalizado (Segundo Cérebro) utilizando o **NotebookLM (Gemini Notebook)**. O modelo foi alimentado com fontes curadas em múltiplos formatos para responder estritamente com base nos dados fornecidos, gerando materiais de estudo validados.

---

## 🎯 Objetivo do Projeto
> "Construir um segundo cérebro focado em [Substitua pelo seu Tema] para ser capaz de [Substitua pela Ação Prática que você quer realizar] com base em fontes validadas e sem viés comercial."

---

## 📋 Diretriz de Comportamento (Prompt do Especialista)
A seguinte diretriz foi inserida nas instruções do notebook para configurar a persona da IA:
*"Comporte-se como um especialista sênior em [Seu Tema]. Suas respostas devem ser estritamente baseadas nas fontes fornecidas, priorizando a profundidade técnica, citando as fontes de origem e apontando contradições ou limitações entre os materiais caso existam."*
